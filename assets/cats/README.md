# Иконки котиков для каталога

Сейчас приложение показывает старые мем-картинки из `kiski kartinki` как
**временные заглушки**. Новых котиков добавляйте в эту папку: они будут
разложены по категориям на главном экране.

## Как организовать набор

Для каждой категории создавайте отдельную папку с латинским названием:

```text
assets/cats/
  category_slug/
    01_first_cat.png
    02_second_cat.png
    03_third_cat.png
```

Количество котиков — это количество разных PNG в папке. Например, если
нужно три котика в одной категории, в её папке должны быть три
самостоятельные картинки: `01_...png`, `02_...png`, `03_...png`. Не делайте
три копии одного котика с перекрашенным фоном.

## Требования к каждой иконке

- Формат: `PNG`, **256 × 256 px**, RGBA и прозрачный фон.
- Стиль: единый **пиксель-арт**; крупные чёткие пиксели без размытия,
  антиалиасинга, градиентов и полупрозрачных краёв.
- Кот занимает примерно 75–85% холста, расположен по центру, не обрезан.
- Не добавлять рамки, фоновые квадраты, текст, подписи, эмодзи и водяные
  знаки: карточка приложения рисует фон сама.
- Один размер пикселя, единая толщина пиксельной обводки, свет и палитра для
  всех котов. Допустима короткая ступенчатая тень в 1–2 оттенка.
- Главный образ должен читаться в маленьком размере 100–150 px.

Когда набор будет готов, каждую новую картинку добавим в каталог приложения
с именем, описанием и категорией. Старые мем-коты тогда можно будет убрать.
