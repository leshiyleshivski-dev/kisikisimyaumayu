# Иконки еды для пасхалок

В этой папке должны лежать **ровно 20** PNG-иконок. Сейчас здесь только
техническое задание: изображения намеренно не сгенерированы и не добавлены.

## Общие требования

- Формат: `PNG` с прозрачным фоном (RGBA).
- Исходный размер: **256 × 256 px** для каждой иконки.
- Видимый предмет должен занимать примерно 75–85% холста и быть по центру.
- Не добавлять текст, рамки, фоновые квадраты, эмодзи или водяные знаки.
- Стиль: **пиксель-арт** в едином стиле с игрой — дружелюбный и слегка
  мемный. Не фотореализм и не векторная/гладкая иллюстрация.
- Пиксели должны быть намеренно крупными и чёткими: без размытия,
  антиалиасинга, градиентов и полупрозрачных краёв. При масштабировании
  использовать только nearest-neighbor / «по соседним пикселям».
- Одинаковые у всех блюд: размер пикселя, толщина пиксельной обводки,
  направление света и ограниченная палитра. Допустима короткая ступенчатая
  тень в 1–2 оттенка.
- Контур и еда должны хорошо читаться и на тёмном фоне `#21191C`.
- Рекомендованный вес файла: до 150 КБ; не использовать анимацию.

В интерфейсе иконки будут показываться примерно в **72–96 px**, поэтому
мелкие детали, тонкие надписи и похожие силуэты лучше избегать.

## Как это будет использоваться

Каждая пасхалка сможет хранить свой рецепт как последовательность имён,
например `fish → milk → tuna_can`. Сам кликер будет сравнивать нажатые блюда
с рецептом и открывать секрет только при полном совпадении порядка.

Если набор станет больше 20, продолжайте нумерацию: `21_...png`, `22_...png`.
