# Архитектура «Кисикисимяумяу»

## Зачем проект разделён на пакет

`kiski_clicker.pyw` — только совместимая точка запуска. Рабочий код находится
в пакете `kisiki`, чтобы интерфейс кликера, Windows-ввод и решатели мини-игр не
зависели друг от друга через один глобальный файл.

```text
kiski_clicker.pyw          точка запуска и обратная совместимость
kisiki/
├── app.py                 кликер, кормилка, навигация и сохранение
├── core.py                тема, ресурсы, WinAPI и отправка ввода
├── __main__.py            запуск через python -m kisiki
└── modules/
    ├── roulette.py        RLT CONTROL
    ├── bongo.py           BONGO BEAT
    ├── buff.py            BUFF TIMING
    ├── miner.py           экран ORE HUNT и безопасный цикл добычи
    ├── miner_vision.py    распознавание руды и уведомлений
    └── volt/
        ├── module.py      экран VOLT GRID и общий жизненный цикл
        ├── current_grid.py  проведение тока
        ├── tumblers.py    распознавание и подбор тумблеров
        └── maze.py        граф и маршрут электролабиринта
```

Корневые файлы `food_catalog.py`, `easter_eggs.py` и `secret_modules.py`
содержат данные и небольшие независимые механизмы. Их не прячем внутрь UI:
каталог еды не должен знать о виджетах, а менеджер модулей — о решателях.

## Направление зависимостей

Зависимости идут только сверху вниз:

```text
kiski_clicker.pyw → kisiki.app → kisiki.modules → kisiki.core
                                  volt.module → volt.* mixins
```

- `core.py` ничего не импортирует из экранов приложения.
- Отдельные игровые модули могут использовать `core.py`, но не друг друга.
- Решатели Volt не создают окна. Они добавляют специализированные методы
  контроллеру `ElectricianModule` через mixin-классы.
- `miner_vision.py` не создаёт окна и не отправляет ввод: он только анализирует
  кадр. Жизненный цикл, фокус GTA и статистика принадлежат `miner.py`.
- `app.py` отвечает за создание экранов и переключение между ними.

Такой порядок не создаёт циклических импортов и позволяет тестировать
компьютерное зрение без запуска окна CustomTkinter.

## Где вносить изменения

- Общие цвета, пути к ресурсам, WinAPI и клавиатурный ввод — `kisiki/core.py`.
- Главный экран, экономика кликера, кормилка и рецепты — `kisiki/app.py`.
- Логика конкретного секретного экрана — соответствующий файл в
  `kisiki/modules`.
- Новый сценарий электрика — отдельный файл в `kisiki/modules/volt`, а в
  `module.py` добавляется только его подключение к общему контроллеру.

Не следует возвращать алгоритмы распознавания в `kiski_clicker.pyw` или
`app.py`: эти файлы не являются складом общей логики.

## Запуск и проверка

```powershell
python kiski_clicker.pyw
python -m kisiki
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm build_kisiki.spec
```

`kiski_clicker.pyw` переэкспортирует прежние публичные имена Volt, поэтому
старые тесты и инструменты, загружавшие `.pyw` напрямую, продолжают работать.
