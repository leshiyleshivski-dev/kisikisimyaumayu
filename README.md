# Кисикисимяумяу

Кошачий кликер с тремя секретными модулями для GTA. Приложение работает на Windows, сохраняет прогресс котиков и умеет в нужный момент открыть игру, выполнить действие и вернуть предыдущее активное окно.

> Приложение автоматизирует ввод мыши. Используйте его на свой риск и учитывайте правила сервера, на котором играете.

## Скачать и запустить

1. Откройте [`dist/Кисикисимяумяу.exe`](dist/Кисикисимяумяу.exe).
2. Нажмите **Download raw file** или значок скачивания справа сверху.
3. Запустите скачанный `Кисикисимяумяу.exe`.
4. Если Windows SmartScreen покажет предупреждение из-за отсутствия цифровой подписи, откройте **Подробнее** и проверьте имя файла перед запуском.

Установка не требуется: приложение собрано в один EXE. Поддерживается Windows 10/11 x64.

## Обычный кошачий кликер

На главном экране доступны шесть котиков. Выберите любого котика и нажимайте прямо на его изображение.

- Каждый клик приносит мяу и мяукоины.
- Быстрые клики собираются в комбо. Каждые пять кликов серии увеличивают бонус, максимум — `+4` к клику.
- **Лапка** добавляет `+1` к обычному клику.
- **Лакомство** добавляет `+1 мяу/сек` пассивного дохода.
- **Лазер** добавляет `+3` к обычному клику.
- **Клубок удачи** можно забирать каждые 45 секунд.
- Счётчик нажатий, лучший комбо, улучшения и прогресс сохраняются автоматически.

Кнопка **Звук: вкл/выкл** в обычном кликере управляет только звуками котиков. Она не влияет на сигнал секретного модуля.

## Как открыть секретный модуль рулетки

1. На главном экране выберите шестого котика — **Grumpy Cat**.
2. Откройте его личный кликер.
3. Нажмите на большую картинку Grumpy Cat и удерживайте левую кнопку мыши примерно **1,25 секунды**.
4. Не отпускайте кнопку, пока вместо кликера не откроется экран секретного модуля.

Индикатора удержания специально нет — это скрытая пасхалка.

Кнопка **← К котикам** скрывает секретный экран и возвращает к Grumpy Cat. Если таймер уже запущен, он продолжит работать в фоне и не сбросится. Чтобы снова увидеть его состояние, ещё раз удерживайте Grumpy Cat. Полное закрытие приложения останавливает таймер.

## Как открыть секретный модуль Бонго

1. На главном экране выберите второго котика — **Бонго**.
2. Откройте его личный кликер.
3. Быстро нажмите на большую картинку Бонго **10 раз подряд**.
4. После десятого клика вместо кликера появится экран **BONGO BEAT**.

Это отдельная пасхалка: десять нажатий нужно сделать с паузой не более 4 секунд между ними. Кнопка **← К котикам** возвращает к Бонго; запущенный таймер продолжает работать в фоне.

### Ритм Бонго

1. Убедитесь, что игра запущена; по умолчанию модуль ищет `GTA5.exe`, но имя процесса можно изменить в самом модуле.
2. Нажмите **F9** или кнопку **Запустить ритм**.
3. Модуль выводит игру на передний план и отправляет **↑**.
4. Через **3 секунды** он отправляет второе **↑**, возвращает прежнее активное окно и запускает следующий таймер.
5. Новый цикл начинается через случайные **7–9 минут**.

| Клавиша | Действие в BONGO BEAT |
| --- | --- |
| **F9** | Запустить ритм; повторное нажатие останавливает его |
| **F11** | Экстренно остановить ритм |

## Как открыть секретный модуль Баффа

1. На главном экране выберите четвёртого котика — **Бафф**.
2. Откройте его личный кликер.
3. Нажмите на большую картинку **3 раза быстро**, сделайте паузу примерно на секунду, затем ещё **3 раза быстро**.
4. После второго тройного удара откроется экран **BUFF TIMING**.

### Ловля шкалы

1. Запустите в GTA мини-игру со шкалой в правом нижнем углу.
2. В **BUFF TIMING** нажмите **F9**.
3. Модуль держит игру на переднем плане и находит зелёный сектор.
4. Модуль один раз отправляет **Space**, когда розовый бегунок заходит в зелёный сектор.

| Клавиша | Действие в BUFF TIMING |
| --- | --- |
| **F9** | Запустить или остановить ловлю шкалы |
| **F11** | Экстренно остановить ловлю |

При переходе между секретными модулями предыдущий автоматически останавливается и перестаёт слушать горячие клавиши.

## Что подготовить в GTA

Перед первым запуском автоматических ставок:

1. Запустите GTA и сядьте за стол рулетки.
2. Дождитесь экрана, на котором видны поле рулетки и строка **ВРЕМЯ** справа снизу.
3. Установите нужный размер ставки средствами самой GTA. Модуль размер ставки не меняет.
4. Вручную наведите **игровую фишку/указатель** на красный ромб цвета в нижней части стола.
5. Не путайте ромбы цвета с красными и чёрными числами:
   - **красный ромб** находится снизу между полями `EVEN` и чёрным ромбом;
   - **чёрный ромб** расположен сразу справа от красного ромба, перед полем `ODD`.
6. Пока игровой указатель находится на красном ромбе, нажмите **F4**.
7. В секретном модуле должна постоянно отображаться зелёная надпись **● Точка захвачена**.

F4 не распознаёт ромб по изображению. Эта клавиша сообщает модулю: «сейчас игровой указатель стоит на красном ромбе». Поэтому положение перед нажатием F4 критически важно.

После перезапуска приложения настройку F4 нужно выполнить заново.

## Горячие клавиши секретного модуля

| Клавиша | Действие |
| --- | --- |
| **F4** | Запомнить, что игровой указатель сейчас находится на красном ромбе |
| **F9** | Запустить автоматические ставки; повторное нажатие останавливает таймер |
| **F11** | Экстренно остановить автоматизацию |

Клавиши F6, F7 и F10 не используются.

## Первый запуск ставок

После подготовки красного ромба:

1. Вернитесь в секретный модуль и проверьте надпись **Точка захвачена**.
2. Убедитесь, что модуль видит процесс `GTA5.exe`.
3. Нажмите **F9** или кнопку **Запустить**.
4. При первом запуске модуль сразу откроет GTA и прочитает реальный таймер рулетки.
5. Если на таймере от `00:34` до `00:10` включительно, модуль сразу сделает ставки.
6. Если осталось от `00:09` до `00:00`, ставить уже поздно. GTA останется открытой, а модуль дождётся следующего безопасного окна.

Во время одной операции модуль:

1. активирует окно GTA;
2. временно удерживает системную мышь в пределах окна игры;
3. делает один клик по красному ромбу;
4. перемещает игровой указатель к чёрному ромбу;
5. делает один клик по чёрному ромбу;
6. возвращает положение системного курсора;
7. возвращает окно, которое было активно до GTA.

Таким образом, за один цикл ставится текущий игровой размер ставки один раз на красное и один раз на чёрное.

## Как работает таймер

После успешной пары ставок выбирается новый случайный интервал от **7 до 9 минут**. Интервал отсчитывается от завершения ставки на чёрное.

- За **10 секунд** до проверки звучит отдельное кошачье уведомление продолжительностью 3 секунды.
- Когда внутренний таймер заканчивается, приложение разворачивает GTA.
- Модуль читает именно строку **ВРЕМЯ** на игровом экране.
- При `00:34–00:10` ставки выполняются сразу.
- При `00:09–00:00` модуль ждёт новый круг и не кликает.
- После успешных ставок снова выбирается случайный интервал `07:00–09:00`.

Пока идёт обычный семи-девятиминутный таймер, можно работать в другом приложении и даже на втором мониторе. Само приложение `Кисикисимяумяу.exe` должно оставаться запущенным.

## Проверка, что игрок остаётся за столом

Во время проверки GTA должна показывать строку **ВРЕМЯ**. Если приложение непрерывно не видит её примерно 3 секунды, оно считает, что игрок больше не находится за столом:

1. автоматизация останавливается;
2. предыдущее окно восстанавливается;
3. звучит аварийный сигнал, если он включён;
4. приложение полностью закрывается.

Это сделано специально, чтобы модуль не отправлял клики в неизвестный экран GTA.

## Звуковые уведомления

У приложения два независимых переключателя:

- **Звук: вкл/выкл** в кошачьем кликере — мемные звуки обычных котиков;
- **Сигнал: вкл/выкл** в секретном модуле — предупреждение перед открытием GTA и аварийный сигнал.

Отключение звука кликера не отключает секретный сигнал. Обе настройки сохраняются между запусками. Секретное уведомление использует первые 3 секунды `cat-iphone-ringtone.mp3`. Громкость проигрывателя выставляется на максимум, но общая громкость Windows и выбранное устройство вывода звука всё равно имеют приоритет.

## Два монитора

Модуль учитывает положение окна GTA на рабочем столе:

- перед ставкой системный курсор сохраняется;
- курсор переносится внутрь окна GTA и временно ограничивается его границами;
- после ставок ограничение снимается;
- курсор возвращается на прежнюю позицию, в том числе на втором мониторе;
- предыдущее активное окно снова получает фокус.

Если модуль ждёт наступления безопасного игрового времени, GTA остаётся активной до появления `00:34–00:10`. Возврат предыдущего окна происходит после ставок или остановки.

## Разрешение экрана

Координаты рассчитываются относительно фактической клиентской области GTA, поэтому поддерживаются стандартные разрешения 16:9:

- `1920×1080` — Full HD;
- `2560×1440` — Quad HD.

Рекомендуется использовать оконный режим без рамки и стандартное положение интерфейса GTA. Сильно изменённая безопасная зона HUD, нестандартный масштаб интерфейса или другое соотношение сторон могут сместить строку **ВРЕМЯ** и ромбы.

## Если что-то не работает

### GTA не подключена

- Убедитесь, что игра запущена.
- По умолчанию модуль ищет процесс `GTA5.exe`.
- Проверьте имя процесса в поле секретного модуля.

### Пишет «Точка не захвачена»

- Откройте стол рулетки.
- Наведите игровой указатель именно на красный ромб цвета.
- Нажмите F4 и проверьте появление зелёной надписи **Точка захвачена**.

### Приложение закрылось само

Во время проверки не была найдена строка **ВРЕМЯ**. Обычно это означает, что игрок вышел из-за стола, открыт другой экран GTA или HUD находится не там, где ожидает модуль.

### Ставка попала не на тот элемент

- Повторно установите игровой указатель на красный ромб и нажмите F4.
- Проверьте разрешение и формат 16:9.
- Верните стандартную безопасную зону HUD.
- Не перемещайте игровой указатель вручную после F4 до первой ставки.

### Не слышно предупреждение

- В секретном модуле включите **Сигнал: вкл**.
- Проверьте громкость приложения в микшере Windows.
- Проверьте активное устройство вывода звука.
- Переключатель обычных звуков котиков здесь ни на что не влияет.

### F-клавиши выполняют действия ноутбука

Попробуйте нажимать сочетания `Fn + F4`, `Fn + F9` или `Fn + F11` — это зависит от настроек клавиатуры.

## Где хранится прогресс

Прогресс кликера и настройки звука сохраняются в:

```text
%LOCALAPPDATA%\KisikiSimyaumyau\progress.json
```

Текущий семи-девятиминутный таймер сохраняется только пока приложение работает. После полного закрытия нужно снова подготовить красный ромб через F4 и запустить модуль через F9.

## Запуск из исходника

Для обычного использования этот раздел не нужен — достаточно готового EXE из папки `dist`.

Понадобятся Python и зависимости:

```powershell
pip install customtkinter opencv-python mss numpy pyinstaller
python kiski_clicker.pyw
```

Сборка одного EXE:

```powershell
python -m PyInstaller --noconfirm build_kisiki.spec
```

Готовый файл появится в папке `dist`.
